# Planet Jumping

Immersive single-page space portal experience — Mars → Earth → Venus.

**Live:** https://jimi18102010-commits.github.io

- Single self-contained `index.html` (inline CSS + JS, no libraries, no build step)
- Canvas-masked 3D-tilting portal window, video preloader, travel transitions, custom cursor
- Responsive at 375 / 768 / 1440 px

Note: some source videos are HEVC; they play in Safari and in Chrome/Edge on devices with HEVC support.
